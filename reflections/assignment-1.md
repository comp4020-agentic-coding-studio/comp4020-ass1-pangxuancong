# Assignment 1 reflection

**What was the breakthrough that moved the work forward?**

The breakthrough didn't happen inside this repo at all — it happened in a
side conversation with ChatGPT about layout and art direction. I'd already
described, in words, the left/right editorial layout I wanted, and Claude
defaulted to the same linear, stacked-section layout it always reaches for.
Same prompt, same result. What actually moved things was generating a
reference image with ChatGPT — a mocked-up NYT-style page showing exactly the
split I had in mind — and handing that image to Claude alongside a short
description. Only then did it build the layout I actually wanted. The words
hadn't changed; a picture instead of more words got a completely different,
correct outcome. That told me some kinds of intent — spatial layout, visual
rhythm — just don't compress into a text prompt the way logic does, however
carefully it's worded, and reference material carries information a
description alone can't.

**What did this work change about who I want to be as a software developer?**

It's pushed me toward wanting to be broad rather than deep. I don't think I
want to go all-in on mastering one stack anymore — I'd rather be comfortable
enough, maybe 80%, across most mainstream tools that I can move between them
without friction. As models get better at actually writing the code, the
scarce skill isn't typing it myself — it's knowing the stack and the business
logic well enough to direct an agent well, and building the harness and
prompts (CLAUDE.md rules, reference images, verification habits) that cut
down rework instead of causing it.
